# 🏠 Rental House App

A backend application for managing rental properties, built with **Java (Spring Boot)** and **Supabase** for authentication and PostgreSQL database services. This app allows users to list rental properties, browse available listings, and make bookings.

---

## 🚀 Features

- 🏘️ List rental properties
- 🔍 Browse available houses
- 🧾 Book and cancel rentals
- 🔐 User authentication using Supabase Auth
- 📊 Persistent data storage with Supabase PostgreSQL
- ⚙️ RESTful APIs with Spring Boot

---

## 🛠️ Tech Stack

- **Java 17+**
- **Spring Boot**
- **Supabase (Auth + PostgreSQL)**
- **PostgreSQL**
- **HTTP Client or Supabase Java SDK**
